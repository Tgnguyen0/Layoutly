1. FIGMA TO CODE (DETERMINISTIC PLUGIN)

⚙️ Thuật toán Node Normalization

  • Chuyển cây SceneNode của Figma sang cấu trúc AltNode tinh gọn.
  • Tự động phát hiện & xóa bỏ các Frame thừa không cần thiết.
  • Tự động gom nhóm thuộc tính padding (top/bottom/left/right) và gap.
  • Tự động gom màu trùng thành CSS Variables & render SVG Icon fallback.

📦 Xuất Starter Project (.ZIP)

  • Chạy thuần túy 100% trong Sandbox của Figma Plugin (không cần server ngoài).
  • Tích hợp thư viện fflate nén mã nguồn thành file .zip.
  • Hỗ trợ đóng gói dự án mẫu hoàn chỉnh: HTML Static, Tailwind CSS, React, Flutter, SwiftUI.

2. GRIDA DESIGN TO CODE (MULTI-TIER ENGINE)

🧬 Giải mã nhị phân Kiwi (.fig)

  • Tích hợp bộ parser nhị phân fig-kiwi.
  • Cho phép đọc trực tiếp file thiết kế Figma .fig / .deck offline mà không bắt buộc phải gọi Figma REST API.

📐 Thuật toán Suy luận Flexbox / Grid

  • Giải quyết triệt để bài toán các phần tử xếp vị trí tuyệt đối (Absolute positioning).
  • Phân tích tọa độ hình học (x, y, w, h) để suy luận phân nhóm phần tử thành các hàng (Row), cột (Column) hoặc Grid đáp ứng.

3. FIGMA TO REACT (TAG TREE ARCHITECTURE)

🌳 Kiến trúc Tag Tree (`buildTagTree.ts`)

Mẫu chuẩn mực nhất cho Figma Plugin: Bóc tách node Figma thành cây đối tượng Tag trung gian trước khi render JSX.

export type Tag = {
  name: string;
  isText: boolean;
  textCharacters: string | null;
  isImg: boolean;
  properties: Property[];
  css: CSSData;
  children: Tag[];
  node: SceneNode;
}
Slide 6 / 10

4. FIGMA CONTEXT MCP (AI-NATIVE PROTOCOL)

🤖 Model Context Protocol (MCP)

  • Không sinh code cứng mà hoạt động như một Server cầu nối dữ liệu cho các Trợ lý AI (Claude, Cursor, Antigravity).
  • Đọc node từ Figma REST API và biến đổi thành Visual Specs JSON tối ưu dung lượng token.

🛠️ Công cụ MCP cung cấp

  • get_figma_file: Lấy thông số tổng quan file.
  • get_figma_node: Lấy spec chi tiết từng Component.
  • download_figma_images: Tự động tải assets ảnh.
  • Để AI tự do biên dịch ra code theo đúng ngữ cảnh dự án.

RÚT RA BÀI HỌC KỸ THUẬT CHO LAYOUTLY

1. Tầng Backend Parser (`FigmaParserService.java`)

Áp dụng thuật toán altNodes của FigmaToCode: Thêm bước tiền xử lý lọc node visible=false, gom nhóm padding trùng lặp và phát hiện Icon SVG tự động.

2. Tầng Cấu Trúc Trung Gian (Layoutly IR Schema)

Học tập mô hình Tag Tree và Grida IR: Tạo lớp DTO LayoutTagDTO trong Spring Boot đứng giữa Parser Service và Code Generator Service.

3. Tầng Figma Plugin (`layoutly-figma-bridge`)

Áp dụng mô hình truyền dữ liệu Message Passing tinh gọn từ Figma to React để trích xuất SceneNode từ Canvas nhanh chóng.

4. Đóng gói Dự án Starter (`ExportService.java`)

Áp dụng cơ chế nén file ZIP từ FigmaToCode để đóng gói toàn bộ mã nguồn React/Vite/HTML cho người dùng tải về.
