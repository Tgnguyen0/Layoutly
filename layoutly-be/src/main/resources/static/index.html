🎨 Layoutly — Backend

Nhập token + fileKey, bấm nút để xem Figma API trả về gì. Không cần Postman.

Lấy tại Figma → Settings → Personal access tokens. Token chỉ lưu tạm trong trình duyệt (localStorage), không gửi lên đâu khác ngoài server local của bạn.
Lấy từ URL Figma: figma.com/design/fileKey/...
Đổi dấu "-" thành ":" — ví dụ node-id=0-1 trên URL → nhập 0:1
Kết quả JSON sẽ hiện ở đây...
